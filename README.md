# STM32\_CAN\_DVCS\_Project

基于STM32和CAN总线的分布式车载控制系统
##项目概述
这是一个基于STM32F103C8T6​和CAN总线的分布式车载控制系统，由三个独立的 ECU（电子控制单元）通过 CAN 总线​ 互联，实现传感器数据采集、电机精确控制和人机交互等功能。系统采用模块化设计，每个 ECU 职责单一、协同工作，主要用于初学者学习（目前正在更新ECU3）

✨ 功能特性
系统级
✅ CAN 总线分布式通信​ – 三节点组网，心跳保活，数据同步
✅ 模块化架构​ – 每个 ECU 独立开发、独立调试
✅ 统一协议​ – 自定义 CAN 报文，支持速度指令、状态反馈、系统控制
✅ 故障诊断​ – 节点离线检测、错误上报、自动恢复
ECU1 – 车身控制单元（人机交互）
✅ OLED 显示​ – 实时显示系统状态、传感器数据、菜单界面
✅ 按键菜单​ – 4 键导航，支持短按/长按/连按
✅ 远程控制​ – 通过按键或 CAN 指令控制电机速度与方向
✅ 系统监控​ – 心跳检测、节点状态、错误告警
ECU2 – 电机驱动单元
✅ PWM 调速​ – 单路 PWM，频率 1kHz，占空比 0–1000
✅ 方向控制​ – PB0/PB1 独立方向引脚，支持正转/反转/刹车
✅ 编码器测速​ – 正交编码器，4 倍频，实时 RPM
✅ PID 闭环控制​ – 位置式 PID，积分限幅、死区、滤波
✅ 多重保护​ – 过流、堵转、过速检测与自动恢复
✅ 自动调参​ – 一键 PID 参数整定
ECU3 – 传感器融合单元
✅ MPU6050 姿态传感器​ – I²C 接口，加速度计/陀螺仪，互补滤波解算姿态
✅ HC‑SR04 超声波​ – 输入捕获测距，2cm–400cm，精度 ±3mm
✅ 电压检测​ – 12 位 ADC，分压采样，实时电压与电量百分比
✅ 传感器融合​ – 低通滤波、异常检测、时间戳同步
✅ 自动校准​ – 一键校准所有传感器
